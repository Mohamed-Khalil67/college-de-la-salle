# Delivery conventions

Read this when finishing a task or preparing a commit or PR.
- Run the project's real typecheck, lint and test commands (from `package.json`) for what you changed. Do not claim a check passed unless you ran it.
- Never commit or push unless explicitly asked.
- Ask before adding a dependency, connecting an MCP server, installing third-party skills, or doing a large refactor.
- Summarise what changed, what you ran, and any follow-up work.
