# Accessibility conventions

Accessibility is part of done.
- Must pass all AXE checks and meet WCAG AA.
- Focus management: visible focus, logical order, focus moved and restored for dialogs and route changes.
- Colour contrast meets AA for text and UI controls.
- Correct ARIA; prefer native elements over ARIA roles.
- Everything works with the keyboard alone.
